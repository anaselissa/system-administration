# Systems and Networks Administration

*A 42 curriculum module focused on building, configuring, securing, and managing computer systems and network infrastructure.*

## About

The **Systems and Networks Administration** module at 42 introduces the fundamentals of system administration, networking, and infrastructure management through practical, hands-on projects.

The module focuses on understanding how operating systems work, configuring and securing server environments, managing network communication, and developing the technical foundations required to deploy and maintain reliable infrastructure.

Rather than relying on traditional lectures, learning takes place through independent research, practical implementation, troubleshooting, and peer evaluation.

## Projects

This repository documents my practical work throughout this module, currently covering two projects:

### 1. Born2beroot

A system administration project focused on building and securing a Linux server inside a virtual machine.

**Key topics:**
- Linux installation and system configuration.
- Virtualization using VirtualBox.
- User and group management.
- Permissions and access control.
- SSH configuration and secure remote access.
- Firewall configuration using UFW.
- System hardening and security policies.
- Encrypted LVM and disk partitioning.
- AppArmor and mandatory access control.
- Bash scripting and system monitoring.
- Automated task scheduling using Cron.

**Environment:** Debian GNU/Linux 13 (Trixie), VirtualBox.

**Evaluation:** Successfully completed and passed three peer evaluations.

### 2. NetPractice

A practical networking project consisting of 10 progressive levels designed to develop an understanding of TCP/IP networking and network configuration.

The objective is to configure network interfaces and routing settings to establish correct communication between different devices and networks.

**Key topics:**
- IPv4 addressing.
- Subnet masks and CIDR notation.
- IP subnetting.
- Network and host addresses.
- Routers and default gateways.
- Routing tables.
- Network communication and connectivity.
- Troubleshooting network configuration issues.

**Format:** Browser-based interactive exercises.

**Progress:** All 10 levels completed and submitted.

## Learning Approach

The 42 learning model emphasizes:

- Independent research and technical documentation.
- Hands-on implementation rather than theoretical memorization.
- Problem-solving and troubleshooting.
- Understanding the underlying concepts behind system and network configurations.
- Peer evaluation and explaining technical decisions to others.
